# 📝 Changelog

All notable changes to **QuantBacktest** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-11-11
### Added
- Continuous integration GitHub Actions workflow with Python 3.10 and 3.11 test matrix.
- Institutional governance documentation: `CONTRIBUTING.md` and `SECURITY.md`.
- Structured version changelog.

## [1.0.0] - 2026-11-08
### Added
- Initial institutional release of Institutional Multi-Asset Walk-Forward & Monte Carlo Backtester.
- Walk-Forward Optimization (WFO) to eliminate curve-fitting and lookahead bias.\n- 1,000-run Monte Carlo resampled simulation with VaR and CVaR estimation.\n- Comprehensive institutional performance tearsheets and drawdowns.\n- Containerized Docker workflow for headless benchmark execution.
