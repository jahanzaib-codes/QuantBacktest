# 🔒 Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
We prioritize system safety, API key security, and execution guardrails. If you identify a potential security issue:

1. **Do not disclose publicly:** Please avoid creating public GitHub issues for security vulnerabilities.
2. **Contact Channel:** Reach out directly to the maintainer via Telegram at [@JanzebBlockdev](https://t.me/JanzebBlockdev) or through verified developer contact channels.
3. **Response Timeline:** We acknowledge all security reports within 48 hours and work diligently to issue patches swiftly.
